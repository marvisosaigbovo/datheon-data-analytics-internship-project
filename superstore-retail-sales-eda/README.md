# Superstore Retail Sales – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on exploring retail sales data to identify business patterns, understand sales performance, and generate meaningful insights.

## Project Objectives

- Perform data wrangling and preparation.
- Identify and profile missing values.
- Analyze customer purchase volume.
- Examine monthly sales trends and seasonality.
- Explore category-wise revenue distribution.
- Generate meaningful business insights.

## Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Matplotlib
- Seaborn
